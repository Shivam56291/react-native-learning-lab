### 🛠️ Tech Stack

<div align="center">

<img src="https://skillicons.dev/icons?i=react,js,expo,sqlite,firebase,vscode,git,github" alt="Tech Stack" />

</div>

- **Framework:** React Native + Expo
- **Navigation:** React Navigation (Native Stack)
- **Authentication:** Firebase Authentication (Email & Password)
- **State Management:** Context API
- **Storage:** SQLite + AsyncStorage
- **Maps:** react-native-maps
- **Camera:** Expo Camera
- **Networking:** Axios for backend requests

### ✅ Features

- 🔑 Signup & Login with **Firebase authentication**
- 🏷️ Add, edit & view favorite places
- 📍 Pick locations & view on interactive map
- 📸 Take photos and attach to places
- 🗄️ Persistent storage using SQLite
- 🔄 Auto-login with token persistence via AsyncStorage
- ⚡ Smooth transitions & animations

### 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/Shivam56291/MyPlaces.git

# Navigate into project
cd MyPlaces

# Install dependencies
npm install

# Run the app
npx expo start

```
