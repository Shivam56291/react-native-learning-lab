# 🧭 NavPlayground

A small Expo app created to practice **React Navigation** concepts.

This project is **not a full application**, but a learning playground to experiment with navigation patterns and APIs.

---

## 📚 What I Practiced

- Adding an **icon button to screen headers**
- Stack Navigation basics
- Drawer Navigation (creating & configuring drawers)
- Bottom Tab Navigation
- Nesting navigators (Stack + Drawer + Tabs)
- Navigation options & screen configuration

---

## 🛠 Tech Stack

- Expo
- React Native
- React Navigation
  - Native Stack
  - Drawer Navigator
  - Bottom Tabs
- Expo Vector Icons
