## ⚡ Quick Start

```bash
# Clone & navigate
git clone https://github.com/yourusername/TravelJournalApp
cd TravelJournalApp

# Install dependencies & start
npm install
npx expo start

```

Works on **Android emulator, iOS simulator, and real devices**
